## Prerequisites

If you are setting up the project from scratch, install [Node.js](https://nodejs.org/) first. Use the current LTS version if you are unsure which one to choose.

## Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal.
